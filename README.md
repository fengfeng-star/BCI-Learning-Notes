# EEG/BCI Learning & Education Project

## 项目简介
这个仓库主要用于记录我个人在学习脑机接口（Brain-Computer Interface, BCI）过程中的学习笔记与代码实践。核心聚焦于 EEG（脑电）信号处理的核心算法。

目的：开发成一套辅助青少年学习脑机接口知识的软件或系统，激发他们对脑科学与人工智能的兴趣。

## 当前包含内容
- 学习笔记：涵盖 EEG 原始数据格式、预处理流程（滤波、ICA）、特征提取（PSD、DE、频带比值、空间特征）以及模型训练（LDA、SVM等）。
- 算法代码：（更新中...）逐步补充特征提取与机器学习模型的 Python 实现代码。
- (注：本仓库仅存放代码与笔记，原始 EEG 脑电数据由于体积较大，不在此托管。)

## 技术栈与工具链
- 编程语言：Python
- 核心库：MNE, NumPy, SciPy, Scikit-learn
- 生态框架：MetaBCI, Brainda

- [ ] 长期目标：设计与开发面向青少年的脑机接口科普与实操交互系统/软件
